2. Funktionsweise dieser Website

Picktwig erstellt Auswahl-Links mit einer Frage und mehreren Antwortmöglichkeiten. Jede Antwort ist einer Ziel-URL zugeordnet. Die gesamte Konfiguration wird im Fragment der Adresse hinter # kodiert. Das Fragment wird beim Abruf dieser Website nicht an den Hosting-Server übertragen. Die Verarbeitung erfolgt ausschließlich per JavaScript im Browser. Die Kodierung ist keine Verschlüsselung: Wer den Link besitzt, kann die Frage, Antwortmöglichkeiten und Ziel-URLs lesen. Bitte trage keine vertraulichen Daten ein.

Beim Öffnen eines Links erscheint die konfigurierte Frage. Erst wenn du eine Antwort auswählst, öffnet der Browser die zugehörige externe Zielseite. Die Auswahl wird nicht gespeichert und beim nächsten Besuch erneut angeboten. Es erfolgt keine permanente HTTP-Weiterleitung.

3. Keine Speicherung der Auswahl

Picktwig verwendet weder Cookies noch localStorage, sessionStorage oder eine Datenbank. Eingaben werden nur für die aktuelle Seite im Arbeitsspeicher verarbeitet. Es gibt keine Auswertung oder Übermittlung deiner Antwort an den Betreiber. Die Konfiguration bleibt Bestandteil des geteilten Links. Browser können URLs im Verlauf, in Lesezeichen oder bei einer Verlaufssynchronisierung speichern; dies richtet sich nach deinen Browsereinstellungen.

Wenn du „Kopieren“ wählst, schreibt die Website den erstellten Link in die Zwischenablage deines Geräts. Scheitert der Zugriff, kannst du den Link manuell kopieren.

4. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Abruf einer Website können durch den Hosting-Anbieter technisch erforderliche Verbindungsdaten verarbeitet werden, beispielsweise IP-Adresse, Zeitpunkt des Abrufs, angeforderte Ressource sowie Browser- und Geräteinformationen.

Weitere Informationen zur Datenverarbeitung durch GitHub findest du in der Datenschutzerklärung von GitHub: GitHub General Privacy Statement.

5. Externe Zielseiten

Nach der Auswahl öffnet dein Browser die jeweilige Zielseite und übermittelt ihr technisch erforderliche Verbindungsdaten, insbesondere deine IP-Adresse. Picktwig setzt für diese Navigation die Referrer-Richtlinie no-referrer. Auf der Zielseite gelten deren Datenschutzbestimmungen. Für deren Datenverarbeitung ist der jeweilige Betreiber der Zielseite verantwortlich.

6. Externe Ressourcen
